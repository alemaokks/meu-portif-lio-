# FiveDev — Developer Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview

Open `index.html` in your browser, or use the VS Code Live Server extension for local development.

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- About, skills, projects, and contact sections
- Lightweight vanilla JavaScript
- Accessible navigation labels and reduced-motion support

## Built with

- HTML5
- CSS3
- JavaScript (ES6)

## Run locally on Windows

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

Recommended: install the **Live Server** extension in VS Code, right-click `index.html`, and select **Open with Live Server**.

No package installation or build step is required.

## Customize before publishing

Search the project for these placeholders and replace them:

- `FiveDev`: change this to the name or professional username you want to display.
- `kevin.alemao.melo@gmail.com`: the contact email currently configured in the portfolio.
- `https://github.com/alemaokks`: update this if your GitHub username changes.
- Project cards: replace the sample descriptions and links with projects you have actually completed.

The project cards are starter examples. Do not describe a sample project as completed work until you have built it and added its real repository or live demo link.

## Deploy with GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the website. The URL will appear in the Pages section.
